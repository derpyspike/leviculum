# What a citation guard reads as "not a file of this tree", once for both:
# scripts/citations.py (the name guard and the drift census) and
# leviculum-std/tests/doc_citations.rs (the line guard) read this file, and
# scripts/check-citation-foreign.py in `just citation-guard` refuses a tree
# where either holds a set of its own.
#
# One entry per line, `<kind> <value>`; `#` starts a comment.

# Extensions that make a `name.ext:number` look like a citation while being
# a `host:port`. A blocklist rather than an extension allowlist on purpose:
# an allowlist silently drops a citation into a file type nobody thought of,
# this can only produce visible noise. `network` is our own server's
# top-level domain, the shipped server list's first entry (`auto_servers.rs`,
# #471 step 3); `example` and `invalid` are the RFC 2606 and RFC 6761 names
# tests and cells dial; `localhost`, `lan` and `internal` are the host names
# of a home network.
non-file-extension com
non-file-extension net
non-file-extension org
non-file-extension io
non-file-extension dev
non-file-extension local
non-file-extension onion
non-file-extension i2p
non-file-extension de
non-file-extension network
non-file-extension example
non-file-extension invalid
non-file-extension localhost
non-file-extension lan
non-file-extension internal
